# 早八 图标设计（Qwen-Image 2.1 本地生成）

生成环境：本机 ComfyUI `<ComfyUI 目录>`（v0.41.0，RTX 5070 Ti Laptop，12 GB）
接口：`http://127.0.0.1:8188`，走 HTTP `/prompt` + `/history`，不依赖网页端。

## 模型与参数（和官方模板 `image_qwen_image_2_1_t2i` 对齐）

| 项 | 值 |
|---|---|
| 主模型 | `qwen_image_2.1_int8_convrot.safetensors`（base，质量更稳） |
| 文本编码器 | `qwen3vl_8b_int8_convrot.safetensors`，CLIP type = `qwen_image` |
| VAE | `qwen_image_2.1_vae_bf16.safetensors` |
| 采样 | euler + simple，cfg 1.0，32 步，EmptyLatent 1024×1024 |
| 负向提示 | 只在 cfg>1 时生效，这里 cfg=1 所以负向实际不起作用 |
| 耗时 | base 32 步约 70 s/张；turbo（8 步固定 sigmas）约 22 s/张 |

turbo 版本可用但几何精度略差（网格会歪、出现重影行），**扁平图标建议用 base**。

## 选定的成品：`成品_v10日出课表/`

构图：上半部「日出」（奶白半圆 + 地平线），下半部 3×3 圆角课表格子，
中间一列两格填金黄色（表示「有课」）。蓝渐变底，和旧版纯蓝底同一个色系。

- 提示词：`p10_grid_gold.txt`，seed 31
- 源图：`源图_1024_原图.png`（ComfyUI 原始输出，保留）
- 切图：`1024/192/144/96/72x*.png`，Lanczos 缩放，文件名和 `manifest.json` 里的引用一致
- 小尺寸验收：`小尺寸预览.png`（144/96/72 各两种蒙版下都能认出「日出 + 课表」）

## 其他候选

`候选对比.png` 是一张八行对比图（原图 + 144 圆形 / 96 圆形 / 72 圆角）。
落选原因简述：

- v8（全白格）：干净但缺重点，小尺寸下和「应用抽屉」图标易混
- v10s32（五列合并格）：最像真实课表，但 72 px 下糊成一团
- v7 / v2（闹钟）：指向「闹钟 App」，不是课表；v2 的橙紫配色也偏离品牌
- v4（3D 书本 + 太阳）：好看但立体风和小尺寸清晰度不划算
- v3（太阳 + 三条杠）：太抽象，像「设置/菜单」
- v1（首版）：地平线穿过格子，网格被光晕冲淡

## 工具

```bash
# 生成（一次一张，串行跑，别并发）
python gen_icon.py --prompt-file p10_grid_gold.txt --prefix v10_grid_gold_s31 --mode base --steps 32 --seed 31

# 切安卓各档尺寸 + 小尺寸预览
python make_icons.py --src <1024.png> --out-dir <目录> --preview out.png

# 候选对比表
python contact_sheet.py --out 对比.png --items a.png:标签 b.png:标签
```

Python 用 ComfyUI 自带的 `python`（有 Pillow）。
