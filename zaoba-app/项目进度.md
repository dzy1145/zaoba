### 数据库表结构

**kb_users** (用户表):
```sql
CREATE TABLE kb_users (
  id INTEGER PRIMARY KEY,
  nickname TEXT DEFAULT '同学',
  periods TEXT,                    -- JSON: [{index,start,end},...]
  theme_mode TEXT DEFAULT 'auto',  -- light/dark/auto
  accent TEXT DEFAULT 'blue',      -- blue/green/purple/orange
  created_at INTEGER
)
```

**kb_semesters** (学期表):
```sql
CREATE TABLE kb_semesters (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL,
  start_date TEXT,                 -- YYYY-MM-DD，第1周周一
  created_at INTEGER,
  sort_order INTEGER DEFAULT 0
)
```

**kb_courses** (课程表):
```sql
CREATE TABLE kb_courses (
  id TEXT PRIMARY KEY,
  semester_id TEXT NOT NULL,
  name TEXT NOT NULL,
  teacher TEXT,
  location TEXT,
  day INTEGER NOT NULL,            -- 0-6（0=周一，6=周日）
  start_period INTEGER NOT NULL,   -- 开始节次 1-12
  end_period INTEGER NOT NULL,     -- 结束节次 1-12
  start_date TEXT NOT NULL,        -- 开始日期
  end_date TEXT,                   -- 结束日期（null=一直上）
  week_type TEXT DEFAULT 'every',  -- every/everyOther
  need_pc INTEGER DEFAULT 0,       -- 0/1
  color TEXT NOT NULL,             -- #4F7CD4
  created_at INTEGER,
  FOREIGN KEY (semester_id) REFERENCES kb_semesters(id) ON DELETE CASCADE
)
```

## 💡 使用提示

### 首次使用流程
1. 打开 App → 进入"我的"页面
2. 点击"+ 新建学期" → 输入学期名称和开学日期
3. 返回"课表"页面 → 点击右下角"+"按钮添加课程
4. 填写课程信息 → 选择星期、节次、日期范围
5. 保存后在周网格中查看课程

### 导入导出
- **导出**: 我的 → 导出课表 → 自动复制到剪贴板
- **导入**: 我的 → 导入课表 → 从剪贴板读取 → 选择模式（覆盖/追加）

### 主题切换
- 我的 → 外观 → 主题色（4种颜色选择）
- 我的 → 外观 → 深色模式（浅色/深色/跟随系统）
