# 早八课表 - 快速启动指南

## 🚀 立即开始 H5 预览测试

### 第一步：安装依赖（如果还没装）

```powershell
cd zaoba-app
npm install
```

### 第二步：启动开发服务器

```powershell
npm run dev:h5 -- --host 0.0.0.0 --port 5174
```

### 第三步：访问

- **电脑浏览器**: `http://localhost:5174/`
- **手机浏览器**: `http://192.168.2.7:5174/` （同一 Wi-Fi）

## ✅ 测试清单

### 基础功能测试（15分钟）

1. **创建学期**
   - 进入"我的"页面
   - 点击"+ 新建学期"
   - 输入：`2026秋季学期`，开学日期：`2026-09-02`
   - 保存

2. **添加课程**
   - 返回"课表"页面
   - 点击右下角蓝色"+"按钮
   - 填写课程信息：
     - 课程名称：`高等数学`
     - 教师：`张老师`
     - 地点：`A101`
     - 星期：`周一`
     - 开始节次：`第1节`
     - 结束节次：`第2节`
     - 开始日期：`2026-09-02`
     - 结束日期：留空（一直上）
     - 上课周次：`每周`
     - 需要带电脑：关闭
     - 课程颜色：选择蓝色
   - 保存

3. **查看课程**
   - 课程应该显示在周一的第1-2节
   - 卡片显示课程名称、地点、教师

4. **周导航**
   - 点击顶部"›"查看下一周
   - 点击顶部"‹"查看上一周
   - 点击中间的日期范围回到本周

5. **编辑课程**
   - 点击课程卡片
   - 修改课程名称为：`高等数学I`
   - 保存
   - 验证修改已生效

6. **添加更多课程测试冲突检测**
   - 添加另一门课：`线性代数`
   - 也选择周一 1-2节
   - 应该看到冲突警告："与 1 门课程时间冲突"

7. **主题切换**
   - 进入"我的"页面
   - 点击主题色色板，切换到绿色/紫色/橙色
   - 验证课表页面的强调色已改变
   - 切换深色模式（如果浏览器支持）

8. **节次表编辑**
   - 我的 → 节次表 → 编辑
   - 修改第1节的时间：`08:00-08:50`
   - 添加一节课（第13节）
   - 保存
   - 返回课表页面，验证节次时间已更新

9. **导出课表**
   - 我的 → 导出课表
   - 应该提示"已复制到剪贴板"
   - 打开文本编辑器粘贴，检查 JSON 格式

10. **导入课表**
    - 复制刚才导出的 JSON
    - 我的 → 导入课表
    - 选择"追加导入"
    - 应该提示导入成功

### 边界情况测试（5分钟）

11. **空状态**
    - 删除所有学期
    - 课表页应显示"还没有学期"
    - 点击"去创建学期"应跳转到我的页面

12. **长文本**
    - 创建课程名称很长的课程：`超级无敌宇宙爆炸霹雳高等数学微积分学`
    - 验证文本是否正确截断（显示省略号）

13. **多节次课程**
    - 创建一门 1-4 节的课程
    - 验证卡片高度正确占据4个节次的空间

14. **隔周课程**
    - 创建一门"隔周"课程
    - 查看不同周，验证课程隔周显示

## 🐛 常见问题排查

### 问题1：页面空白
**可能原因**: 数据库初始化失败  
**解决**: 打开浏览器控制台（F12），查看错误信息

### 问题2：课程不显示
**可能原因**: 
- 日期范围不包含当前周
- 学期未选择

**解决**: 
- 检查课程的开始/结束日期
- 确认顶部学期选择器已选中学期

### 问题3：导入失败
**可能原因**: JSON 格式错误  
**解决**: 
- 确保复制的是完整的 JSON（包括开头的 `{` 和结尾的 `}`）
- 检查 JSON 中是否有语法错误

### 问题4：主题不生效
**可能原因**: CSS 变量未加载  
**解决**: 刷新页面（Ctrl+F5 强制刷新）

## 📱 真机测试准备

H5 测试通过后，可以进行真机测试：

### 1. 编译 App 代码
```powershell
npm run build:app
```

### 2. 启动调试基座
```powershell
& 'HBuilderX/cli.exe' launch app-android `
  --project 'zaoba-app' `
  --deviceId '<设备序列号>' `
  --playground standard
```

### 3. 真机测试重点
- SQLite 数据持久化（关闭 App 重开数据仍在）
- 触摸手感（按钮点击、滑动流畅度）
- 布局适配（360px 宽屏幕）
- 性能（冷启动时间、页面切换速度）

## 🎨 应用图标准备

正式打包前需要准备应用图标：

### 图标要求
- 尺寸：1024×1024 像素
- 格式：PNG（透明背景或纯色背景）
- 内容：建议包含"早八"文字或数字"8"

### 生成四档图标
需要生成以下尺寸：
- hdpi: 72×72
- xhdpi: 96×96
- xxhdpi: 144×144
- xxxhdpi: 192×192

放置在：`zaoba-app\icons\`

## 📦 云打包流程

### 打包前检查
```powershell
# 1. 确认项目已导入
& 'HBuilderX/cli.exe' project list

# 2. 确认已登录（需要用户手动登录）
& 'HBuilderX/cli.exe' user info
```

### 执行打包
```powershell
& 'HBuilderX/cli.exe' pack `
  --project 'zaoba-app' `
  --platform app-android `
  --android.packagename 'com.daidi.zaoba' `
  --android.androidpacktype 3 `
  --safemode true
```

### 安装到真机
```powershell
adb install -r "zaoba-app\dist\release\apk\早八-v1.0.0.apk"
```
