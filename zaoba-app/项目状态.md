## 🎯 当前状态：外观改造完成，等待真机验收

**已在真机跑通**（设备 `<设备序列号>` / PLK110 / Android 16）：

```powershell
& 'HBuilderX/cli.exe' launch app-android `
  --project 'zaoba-app' `
  --deviceId '<设备序列号>' `
  --playground standard
```

**踩过的坑（下次直接照做）**：
- **CLI 编译前必须先 `npm install`**，否则报 `can not found node_modules`。
  国内镜像：`npm install --registry https://registry.npmmirror.com`
- adb 序列号会变，动手前先 `adb devices` 核对（旧文档写的 `<设备序列号>` 已失效）。

**外观改造要点（本次）**：
- 主题令牌改为挂在**页面根 view 的 `.theme-*` 类**上。原来挂在 `page.theme-*`，
  但 uni-app 里 `page` 编译成 `uni-page-body`，且 App 端没有 `documentElement`，
  结果变量全部丢失（按钮白字无底、色块消失）。统一入口：`utils/theme.js`
  的 `resolveThemeClass / applyStatusBar / applyTabBar`。
- **系统深色检测用 `getSystemInfoSync().osTheme`**，`theme` 字段在 App 端为空。
- `auto` 模式在 JS 里就解析成具体 `light/dark`，避免 CSS 媒体查询与 JS 判断打架
  （App webview 的 `prefers-color-scheme` 与 `osTheme` 可能不同步）。
- 顶栏加 `--status-bar-height` 内边距；节次表页补 `navigationStyle: custom`
  （否则原生导航栏与自绘顶栏重复）。

**Apple 风格重做（第二轮，用户嫌丑后）**：
- 视觉语言整体换掉：**tinted 课程卡片**（浅底 + 同色系深字 + 左侧色条）取代
  满饱和度色块 —— 由 `utils/color.js` 的 `courseTint()` 从课程色推导，深浅各一套。
- 令牌换成 iOS 一套（`App.vue`）：系统字体、连续圆角、分组背景 `#f2f2f7`、
  卡片 `#fff`、发丝分隔线 `rgba(60,60,67,.16)`；深色 `#000 / #1c1c1e`。
  文本样式按 iOS 的 Large Title / Headline / Body / Footnote 分档。
- 顶栏 / 导航栏 = **毛玻璃材质**（`backdrop-filter: blur(20px) saturate(180%)`），
  内容从下面滚过；「我的」是 iOS 大标题 + 滚动后浮出迷你栏（`onPageScroll`）。
- TabBar 补图标（`src/static/tab/`）：用 Windows 自带 **Segoe Fluent Icons** 渲染的
  PNG，4 档强调色 + 灰，`applyTabBar()` 随主题换选中图标。
- 「我的」改成 iOS 分组列表；深色模式用**分段控件**（不是 picker）；色点带勾选。
- 弹窗改成 iOS 表单：抓手条 + `取消 / 标题 / 保存` 头栏 + 分组行 + 底部红色删除行；
  打开时 `uni.hideTabBar()` 遮住原生 TabBar（原生 tabbar 盖不住，会穿帮）。
- 单色图标资源在 `src/static/`（TabBar / 空状态 / 编辑 / 删除），App 图标在 `icons/`。

## 🗄️ 数据库设计

### 表结构

**1. kb_users（用户表）**
```sql
CREATE TABLE kb_users (
  id INTEGER PRIMARY KEY,                -- 固定为1（单用户）
  nickname TEXT DEFAULT '同学',
  periods TEXT,                          -- JSON: [{index,start,end},...]
  theme_mode TEXT DEFAULT 'auto',        -- light/dark/auto
  accent TEXT DEFAULT 'blue',            -- blue/green/purple/orange
  created_at INTEGER
)
```

**2. kb_semesters（学期表）**
```sql
CREATE TABLE kb_semesters (
  id TEXT PRIMARY KEY,                   -- UUID
  name TEXT NOT NULL,                    -- 例如：2026秋季学期
  start_date TEXT,                       -- YYYY-MM-DD，第1周周一
  created_at INTEGER,
  sort_order INTEGER DEFAULT 0
)
```

**3. kb_courses（课程表）**
```sql
CREATE TABLE kb_courses (
  id TEXT PRIMARY KEY,                   -- UUID
  semester_id TEXT NOT NULL,
  name TEXT NOT NULL,
  teacher TEXT,
  location TEXT,
  day INTEGER NOT NULL,                  -- 0-6（0=周一，6=周日）
  start_period INTEGER NOT NULL,         -- 1-12
  end_period INTEGER NOT NULL,           -- 1-12
  start_date TEXT NOT NULL,              -- YYYY-MM-DD
  end_date TEXT,                         -- null=一直上
  week_type TEXT DEFAULT 'every',        -- every/everyOther
  need_pc INTEGER DEFAULT 0,             -- 0/1
  color TEXT NOT NULL,                   -- #4F7CD4
  created_at INTEGER,
  FOREIGN KEY (semester_id) REFERENCES kb_semesters(id) ON DELETE CASCADE
)
```

### 索引
```sql
CREATE INDEX idx_courses_semester ON kb_courses(semester_id);
CREATE INDEX idx_courses_date ON kb_courses(start_date, end_date);
CREATE INDEX idx_courses_day ON kb_courses(day);
```

## 📦 核心功能说明

### 1. 数据库层（services/database.js）

**关键函数**:
```javascript
// 初始化
initDatabase()                          // App端SQLite + H5端LocalStorage

// 用户设置
getUser()                               // 获取用户信息
updateUser(fields)                      // 更新用户字段

// 学期管理
listSemesters()                         // 获取所有学期
createSemester(data)                    // 创建学期
updateSemester(id, data)                // 更新学期
deleteSemester(id)                      // 删除学期（级联删除课程）

// 课程管理
listCourses(semesterId)                 // 获取学期的所有课程
createCourse(data)                      // 创建课程
updateCourse(id, data)                  // 更新课程
deleteCourse(id)                        // 删除课程

// 导入导出
exportAll()                             // 导出完整JSON
importAll(data, mode)                   // 导入（mode: overwrite/append）
```

**特性**:
- 双态存储：App端SQLite，H5端LocalStorage，业务代码无感知
- 外键级联删除：删除学期自动删除所有课程
- 自动初始化：首次运行创建默认12节次表

### 2. 日期工具（utils/schedule.js）

**核心算法**:
```javascript
// 基础日期
formatDate(date)                        // Date → 'YYYY-MM-DD'
parseDate(str)                          // 'YYYY-MM-DD' → Date
addDays(date, n)                        // 日期加减
weekMonday(date)                        // 获取周一
formatWeekRange(monday)                 // '9/2 – 9/8'

// 周次换算
weekIndexOf(semesterStart, date)        // 日期→第几周
dateOfWeek(semStart, week, dayIdx)      // 第N周星期X→日期
scheduleFromWeeks(...)                  // 周次录入→日期制
weeksFromSchedule(...)                  // 日期制→周次展示

// 课程匹配
hitDate(course, date)                   // 判断某天是否上课（支持隔周）
detectConflicts(course, allCourses)     // 检测课程冲突
```

**课表主页（pages/index/index.vue）**:

- 悬浮添加按钮（FAB）

**个人页（pages/mine/mine.vue）**:

## 📋 导入导出格式

### JSON 格式
```json
{
  "version": "1.0",
  "exportTime": 1697097600000,
  "app": "早八",
  "user": {
    "nickname": "同学",
    "periods": [
      { "index": 1, "start": "08:00", "end": "08:45" },
      { "index": 2, "start": "08:50", "end": "09:35" }
    ],
    "themeMode": "auto",
    "accent": "blue"
  },
  "semesters": [
    {
      "id": "1697097600000-abc123",
      "name": "2026秋季学期",
      "startDate": "2026-09-02",
      "createdAt": 1697097600000,
      "sortOrder": 0
    }
  ],
  "courses": [
    {
      "id": "1697097600000-def456",
      "semesterId": "1697097600000-abc123",
      "name": "高等数学",
      "teacher": "张老师",
      "location": "A101",
      "day": 0,
      "startPeriod": 1,
      "endPeriod": 2,
      "startDate": "2026-09-02",
      "endDate": null,
      "weekType": "every",
      "needPc": false,
      "color": "#4F7CD4",
      "createdAt": 1697097600000
    }
  ],
  "currentSemesterId": "1697097600000-abc123"
}
```

### 导入模式
- **overwrite（覆盖）**: 先显式清空课程 + 学期（不能靠外键级联），再导入；`currentSemesterId` 一并恢复
- **append（追加）**: 保留现有数据，学期/课程一律发新 id 再写入（同小程序云端 add 的行为）
- 用户设置（昵称/节次表/主题/强调色/行高列宽）逐项校验后才覆盖；坏字段计入 `skipped` 返回

> 细节与踩坑见 `早八-项目记忆.md`「八、导入导出格式」和「七、不能回退的技术决定」。

## 🐛 已知问题和解决方案

### 问题1：调试基座启动失败
**可能原因**:
- 项目未导入到 HBuilderX
- 设备未正确连接
- HBuilderX 未登录

**解决方案**:
1. 运行 `adb devices` 确认设备连接
2. 运行 `cli project list` 确认项目已导入
3. 运行 `cli user info` 确认已登录
4. 手动重启 HBuilderX

### 问题2：SQLite 初始化失败
**可能原因**: manifest.json 未开启 SQLite 模块

**解决方案**: 确认 `manifest.json` 中有：
```json
"modules": {
  "SQLite": {}
}
```

### 问题3：页面空白或闪退
**可能原因**: 
- 数据库初始化错误
- 代码语法错误
- 依赖未安装

**解决方案**:
1. 检查浏览器控制台错误（H5 模式）
2. 检查 HBuilderX 控制台日志（App 模式）
3. 运行 `npm install` 确保依赖完整
